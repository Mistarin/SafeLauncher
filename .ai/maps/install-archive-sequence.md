# Install and Archive Sequence

```text
archive selection
 → inspect/capacity/candidate executable discovery
 → sandboxed staged extraction
 → validation and transfer
 → GameDatabase record creation/update
 → installed/playable local projection
 → artwork/metadata refresh
 → optional private library sync
```

Restoring a cloud-only/not-installed record must update its existing stable identity when possible instead of creating a duplicate. Deleting files and deleting a library record are separate operations.
