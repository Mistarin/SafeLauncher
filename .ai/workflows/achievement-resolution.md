# Workflow: Achievement Resolution

1. Resolve a schema from local or remote providers.
2. Validate API names and provenance.
3. Persist schema and local observations.
4. Watch supported local state files where applicable.
5. Merge unlocks into account-wide profile state without discarding stronger provenance.
6. Schedule batch/background refreshes through the request manager where available.
7. Keep local unlock state when remote schema/state is unavailable.
